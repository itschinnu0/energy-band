# Phase 0 — Repository and Agent Setup

## Objective
Establish a clean repository that can be implemented phase-by-phase.

## Tasks
- Create the architecture from `AGENTS.md`.
- Create package `__init__.py` files.
- Create placeholder modules with docstrings only where needed.
- Create `pyproject.toml` for Python 3.12 and project dependencies.
- Add pytest configuration.
- Add a minimal README.
- Do not implement device physics yet.
- Do not build the final GUI yet.

## Acceptance
- Project imports cleanly.
- `pytest` discovers tests.
- No device equations exist outside the future physics modules.
- Repository tree matches the planned architecture.

## Deliverable
A clean skeleton ready for Phase 1.
